# ShopSphere E-commerce Data Analytics & Automation

An end-to-end e-commerce data analytics project focused on automated data cleaning, transformation, validation, KPI analysis, and dashboard development.

## Project Overview

ShopSphere demonstrates how raw e-commerce data can be transformed into a clean, validated, dashboard-ready dataset using Python and Pandas.

## Tools & Technologies

- Python
- Pandas
- NumPy
- SQL
- Excel
- Power BI
- Looker Studio
- Google Colab
- Streamlit

## Key Results

- Processed 5,000 e-commerce records
- Expanded dataset from 18 to 28 analytical columns
- Created 10 analytical features
- 0 missing values after cleaning
- 0 duplicate records
- 0 negative quantity records
- 0 amount calculation mismatches
- Generated a dashboard-ready processed dataset
- Developed a Streamlit dashboard for KPI analysis

## Project Components

### Data Processing
Automated cleaning, data type conversion, transformation, feature engineering, and validation using Python/Pandas.

### Automation Testing
Implemented automated checks for missing values, duplicates, negative quantities, calculated amounts, and order counts.

### Dashboard
Developed a Streamlit application for KPI-oriented analysis and filtered data exploration.

## Project Status

Core data processing, automation testing, processed dataset generation, and Streamlit dashboard development are completed.

Production-grade persistent scheduling and cloud deployment are future enhancements.
